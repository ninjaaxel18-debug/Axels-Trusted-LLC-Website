AXELS TRUSTED WEBSITE V5.2

1. Unzip this package.
2. Replace the existing website files in your GitHub website folder.
3. Keep the hidden .git folder.
4. Keep CNAME so axelstrusted.com remains connected.
5. Commit in GitHub Desktop and click Push origin.
6. Wait 1-3 minutes and press Ctrl+F5 on the live website.

The top navigation, estimate button, project button, phone number, and email are now real HTML links rather than parts of one flat image.
