Plan your tile project

Tell us where the tile will be installed, the approximate size of the area and whether existing tile needs to be removed or replaced. Photos help explain the current condition. If you have already chosen tile, share its type and dimensions when discussing the estimate. If you are still deciding, mention that so material choices can be considered in the project scope.

Preparation matters to the finished result

A tile project involves more than the visible tile. The existing surface, preparation, layout and finishing details all affect the work required. Discuss what is included in the estimate and what needs to happen before installation. We assess your request before committing to a particular application or installation approach.

Tile as part of a remodel or a smaller job

Tile work can be requested as a separate improvement or discussed alongside kitchen or bathroom remodeling. When several updates are planned, explain the whole project so the sequence and agreed responsibilities are clear. You can use the same free estimate form for a standalone tile job.
